# Index

## Standard Files
- `PERSONA.md` — who I am (name, vibe, style, evolution log)
- `CREED.md` — what I believe (values, philosophy, boundaries, dominion)
- `BOND.md` — who I serve (the operator: brief shape, priorities, client context, sender-to-project routing, interruption tolerance)
- `MEMORY.md` — what I know (curated long-term knowledge)
- `CAPABILITIES.md` — what I can do (built-in + learned abilities + tools)
- `PULSE.md` — what I do autonomously (the 08:30 brief, and the 30-minute relay for fires, intake, Slack replies, and digests, driven by Cursor automations)

## Session Logs
- `sessions/<date>/<run id>.md` — raw notes, one file per run; curated into MEMORY.md by the brief run or in chat

## Working Files
- `briefs/<date>.md` — each morning brief as posted, plus its Slack thread ts (digests reply in that thread)
- `portfolio.md` — one line per project: tempo, what it waits on, since when
- `routing.md` — operator-taught mappings: sender domains, addresses, and channels to project ids
- `unsorted/<date>/<run id>.md` — intake no mapping could place; lands in the next brief

## Project Memory
- `{project-root}/_bmad/memory/aor/projects/<id>/` — owned by each project's PM; I add inbox items and daily log lines only
